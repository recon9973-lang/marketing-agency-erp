# 이미지 제작 툴 (카드뉴스 · 공지 팝업) 기획안

2026-07-03 대표 지시로 리서치·브레인스토밍 진행. **예시 프로토타입을 먼저 제시하고 승인 후 ERP에 구현**한다.

## 리서치 요약 (Canva/미리캔버스/망고보드/Pinterest 계열)

- 표준 규격: 인스타 피드 1080×1080(1:1), 세로 4:5(1080×1350), 스토리 9:16(1080×1920).
  웹 팝업은 600×800 내외, 링크 배너는 1200×628이 일반적.
- 좋은 카드뉴스의 공통점: ① 커버(표지)가 승부처 — 큰 타이포 + 여백,
  ② 본문은 고딕 계열이 가독성 우수, 행간은 폰트 크기의 약 1.6배,
  ③ 레이아웃 감각(정렬·여백)이 장식 기술보다 중요.
- 기존 툴의 강점: 미리캔버스=국내 친화 템플릿·쉬운 UI, 망고보드=텍스트 콘텐츠 특화,
  Canva=글로벌 감성 템플릿 방대. 공통 UX 패턴: **템플릿 갤러리 → 캔버스 편집 →
  우측 속성 패널 → 내보내기**.
- 차별화 기회: 범용 툴에는 없는 **ERP 거래처 데이터 자동 삽입**
  ({업체명}/{전화}/{주소} 토큰) — 담당자가 거래처별 콘텐츠를 반복 제작하는
  마케팅 대행사 워크플로우에 특화.

## 방향 검토 (브레인스토밍)

| 옵션 | 내용 | 판단 |
|---|---|---|
| A. 자체 캔버스 편집기 | 템플릿 + 텍스트/배경 편집 + PNG 내보내기, 전부 브라우저에서 | ✅ **채택** — 외부 API 불필요, ERP 데이터 연동 자유로움 |
| B. 외부 편집기 SDK 임베드 | Canva Embed 등 | 보류 — 계약/과금, 거래처 데이터 연동 제한 |
| C. AI 이미지 생성 | 프롬프트로 배경/일러스트 생성 | 2단계 — 생성 API 계약 후 A에 "AI 배경" 버튼으로 추가 |

## 채택안(A) 기능 명세 — 대표 요구사항 매핑

| 요구사항 | 구현 |
|---|---|
| 이미지 사이즈 필터링 | 5종 프리셋(정사각형/4:5/스토리/웹팝업/배너) 칩 필터 → 갤러리와 캔버스 규격 동시 전환 |
| 예시 이미지(템플릿) | 스타일별 템플릿 갤러리(공지/프로모션/카드뉴스 커버/감성/스토리/팝업/배너…) — 지속 추가 |
| 텍스트 완전 제어 | 내용·폰트 종류·크기·굵기·색상·정렬 + **캔버스에서 드래그로 위치 이동**, 레이어 추가/삭제 |
| 배경 교체 | 컬러/그라디언트 스와치 + **내 사진 업로드** + 어둡게(글자 가독) 슬라이더 |
| 업체 데이터 활용 | 거래처 선택 → {업체명}{전화}{주소} 토큰 자동 치환 (ERP 거래처 연동) |
| 결과물 | 원본 해상도 PNG 다운로드 (브라우저 캔버스 렌더링, 서버 비용 0) |

## ERP 구현 계획 (승인 시)

1. `/studio` 메뉴 추가 — 프로토타입 편집기를 ERP 안으로 이식, 거래처 목록 실연동.
2. 템플릿을 DB화(관리자가 추가 가능) + "내 디자인 저장/불러오기".
3. 제작물을 파일 전달(3차)와 연결 — 만든 이미지를 바로 채팅/협업방에 공유.
4. (2단계) 웹폰트 번들(프리텐다드 등) 적용, AI 배경 생성 연동.
