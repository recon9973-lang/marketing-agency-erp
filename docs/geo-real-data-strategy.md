# VENOM GEO 실측 데이터 전략 (Real-Data Strategy)

> 목적: **실현 가능한 GEO를 실제로 서비스**한다.
> 원칙(사장님 지시): **실측 데이터만 노출한다. 연결 안 된 건 "데모/미연결"로 명시한다.
> 자동화 불가한 부분은 수동 입력을 안내한다.** 목업을 실측처럼 보여주지 않는다.

---

## 1. 데이터 등급 체계 (4-tier) — 모든 GEO 수치에 배지로 표기

| 등급 | 의미 | UI |
|------|------|-----|
| 🟢 **실측(measured)** | 실제 API 응답 기반 | 초록 배지, 그대로 노출 |
| 🟡 **근사(approx)** | 실측 신호로 계산한 추정(원천이 정확치 아님) | 노랑 배지 + "추정" 명시 |
| ⚪ **데모(demo)** | 연결 안 됨 — 예시 데이터 | 회색 배지 + 흐림/"예시" 워터마크, 숫자 신뢰 금지 |
| 🔵 **수동(manual)** | 자동 불가 → 사람이 입력 | 파랑 배지 + 입력 가이드 |

핵심: **데모는 절대 실측처럼 보이면 안 된다.** 숫자를 흐리게 하거나 "연결 필요" 빈 상태로 바꾼다.

---

## 2. 현행 진단 — GEO 시스템이 둘

- **`geo-engine/` (실측 엔진)** → `/geo` 모니터링. 4대 AI API를 실호출해 인용을 탐지하고 `GeoCitationScore`에 저장. **진짜 실측**(키 설정 시). VENOM GEO의 정당한 코어.
- **`geo-studio/` (M1~M5)** → `/geo-scan`·`/geo-cep`·`/journeymap(구 geo-path)`·`/geo-planner`. 파이썬 프로토타입 이식본으로 **`mockResponse`·`mockEmbedding` 목업**. 검색량·SERP만 네이버 실측 프로바이더 연결.

문제: 실측 엔진이 있는데 **화면은 목업 스튜디오를 보여준다.**

## 3. 능력별 실측 가능성 매트릭스 (핵심)

| GEO 능력 | 참고 화면 | 실측 방법(실제 API) | 현재 | 목표 등급 |
|----------|-----------|---------------------|------|-----------|
| **AI 인용률 측정** | 스캐너·모니터링 | ChatGPT·Perplexity·Gemini·Claude API 실호출 → 브랜드 언급/인용 탐지 | 🟢`/geo` / ⚪`/geo-scan` | 🟢 실측 |
| **검색량(상대 트렌드)** | 검색량 조회 | 네이버 데이터랩 | 🟢 | 🟢 실측 |
| **검색량(절대 월간)** | 검색량 조회 | 네이버 검색광고 API | 🟢(키) | 🟢 실측 |
| **SERP 상위 URL** | 상위 URL 분석 | 네이버 검색 API | 🟢 | 🟢 실측 |
| **연관 키워드** | CEP·여정 시드 | 네이버 검색광고 연관키워드(RelKwdStat)·자동완성 API | ⚪ 미구현 | 🟢 **구현 가능** |
| **CEP 군집 발굴** | CEP 파인더 | 실제 AI 답변 프로브 + **OpenAI 임베딩** + k-means | ⚪ 목업(답변·임베딩) | 🟢 **임베딩 연동 시** |
| **상위 URL 코사인 유사도** | 슬라이드13 | SERP URL 본문 크롤 + 임베딩 | ⚪ 없음 | 🟢 임베딩 연동 시 |
| **인구통계(성/연령)** | — | 네이버 데이터랩 성별·연령 비율 | ⚪ 미구현 | 🟡 부분 실측 |
| **검색 여정(이전/이후 검색)** | GEO 여정 | ❌ 공개 API 없음 — 리스닝마인드 **독점 클릭스트림** | ⚪ 목업 | 🟡 **근사** or ⚪ 데모 |

### 실측 불가 항목의 정직한 처리
- **검색 여정 클릭스트림**: 네이버·구글 모두 "이전/이후 검색"을 공개 API로 주지 않음.
  → (a) 연관어 확장 그래프로 **근사**하고 "클릭스트림 아님·추정" 명시, 또는
  (b) 리스닝마인드(Ascent Korea) API 제휴 시 실측. **가짜 트리를 실측처럼 보이면 안 됨.**
- **구글 AI Overview 인용**: API 없음 → SerpAPI 유료 또는 **수동 캡처 입력** 가이드.

## 3-B. 실측 API 확정 스펙 (연구 결과 — 출처 검증)

| 데이터 | 판정 | 실제 스펙 |
|--------|------|-----------|
| **네이버 검색광고 RelKwdStat** | 🟢 **무료·실측** | `GET api.searchad.naver.com/keywordstool?hintKeywords=…&showDetail=1`, HMAC-SHA256. 연관키워드 ~1000개 + **절대 월간 PC/모바일 검색수** 반환. `< 10`은 문자열. 레이트리밋 비공개(429 주의). **CEP·여정 시드의 핵심 무료 소스** |
| 네이버 데이터랩 | 🟢 무료·상대치 | 트렌드 0~100 지수(절대치 아님), 1000콜/일 |
| 네이버 검색 오픈API | 🟢 무료 | 블로그/뉴스/웹/지역 상위 URL, 100/콜·25k/일 |
| 자동완성·연관검색어 | ⚪ 스크래핑만 | 공식 API 없음 → 데모 표기 |
| Perplexity Sonar | 🟢 유료 | `search_results[]`+`citations[]` URL 반환 |
| OpenAI web_search | 🟢 유료 | `url_citation` 주석, $10/1k |
| Claude web search | 🟢 유료 | `web_search_result_location`, $10/1k |
| Gemini grounding | 🟢 유료 | URI가 리다이렉트 스텁 → 해석 필요 |
| 구글 AI Overview | 🟢 유료(SerpApi) | 공식 API 없음, ~$150/월·15k |
| 네이버 Cue:/AI브리핑 | 🔵 수동 | API/파서 없음 확인 |
| OpenAI 임베딩 | 🟢 저렴 | small $0.02/1M(1536d), 한국어 OK. BGE-m3/Upstage A/B 후보 |
| **리스닝마인드 클릭스트림** | 🟢 **유료 제휴** | Ascent Korea가 **데이터 API + MCP 제공**(월 15억 검색). "이전/이후 검색" 실측은 제휴로 가능(가격 비공개) |

**실무 KPI(2025 컨센서스, 실측 가능)**: 언급률·인용률·SoV(경쟁 대비 점유)·답변 내 위치·AI 추천 유입(GA4).
**과장(측정 어려움)**: 단일 "AI 순위" 숫자, 매출 귀인(제로클릭). → 이런 건 데모/추정 표기.

## 4. 실측 전환 로드맵 (우선순위 — real-first)

1. **정직성 레이어 먼저** — 모든 GEO 지표에 4-tier 배지. 목업 화면(`/geo-scan`·`/geo-cep`·`/journeymap(구 geo-path)`)을
   "데모 · 실측 미연결"로 명시(가짜 숫자 흐림/빈 상태). `mocked` 플래그가 이미 스캐너에 있음 → UI로 승격.
2. **임베딩 프로바이더 연동**(OpenAI `text-embedding-3`) — `cep/finder.ts`가 이미 주입 구조.
   → CEP 군집·상위 URL 유사도 **실측화**.
3. **연관 키워드 실측**(네이버 검색광고 RelKwdStat) — 현재 `NotConfiguredError`. 구현 시 CEP·여정 시드 실측.
4. **스캐너 실측 통합** — `geo-studio/scanner` 목업을 `geo-engine` 실측 어댑터로 교체(중복 제거).
   목업 M1 → 실측 `/geo`와 하나로.
5. **검색 여정 재정의** — 클릭스트림 근사(연관어 그래프) + "추정" 워터마크, 또는 리스닝마인드 제휴 검토.

---

## 5. 정직한 UI 규칙 (전 화면 공통)

- 모든 지표 카드/타일에 **tier 배지**(🟢실측 / 🟡근사 / ⚪데모 / 🔵수동).
- **데모 데이터**: 숫자 흐림 + "예시" 워터마크, 또는 "연결 필요" 빈 상태. 실측처럼 보이는 표현 금지.
- **자동 불가**(AI Overview, 클릭스트림): 수동 입력 폼 + 캡처 링크 안내.
- `/integrations`에 GEO 실측 키(엔진·임베딩·네이버) 연결 상태를 항목별 노출(레지스트리 확장).
