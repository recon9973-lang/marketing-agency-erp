# 역할별 워크플로우 파이프라인 (VENOM 마케팅 ERP)

화면 단위가 아니라 **역할 4단(최고관리자·관리자·마케터·거래처)** 으로 나눠 각 역할의
운영 흐름(파이프라인)을 먼저 정의하고, 그 순서대로 구현한다.

범례: ✅ 구현됨 · 🔶 부분/배선 필요 · ⬜ 미구현

---

## 1단계 · 최고관리자 (SUPER_ADMIN) — 총괄 운영 파이프라인
모든 데이터의 발원지. 조직·거래처 세팅과 계약·정산·권한의 시작점.

| # | 단계 | 핵심 | 경로 | 상태 |
|---|------|------|------|------|
| 1 | 거래처 온보딩 | 병원 등록(HospitalProfile SoT)·업종·담당 마케터 배정 | /clients | ✅ |
| 2 | 계약 체결 | 상품(Product) 구성·계약서 서명·서명 시 업무 자동 생성 | /contracts | ✅ |
| 3 | 조직·권한 | 직원 초대·역할·접근 범위 | /settings | ✅ |
| 4 | 전사 모니터링 | 전체 업무·지연·미수금·지출 | /work | 🔶 |
| 5 | 정산·재무 | 청구·입금·지출 | /finance | ✅ |
| 6 | 최종 승인 | 상위 승인·의료법 에스컬레이션 | /approvals | ✅ |

담당 병원 마케팅 실행. 거래처 인사이트가 핵심.

| # | 단계 | 핵심 | 경로 | 상태 |

외부 포털(portalToken) 기반, 로그인 없는 토큰 접속. ERP 대시보드가 아닌 포털에 존재.

| # | 단계 | 핵심 | 경로 | 상태 |
|---|------|------|------|------|
| 1 | 초대·접속 | 포털 토큰 | /portal/[token] | ✅ |
| 2 | 설문 응답 | 초기/분기 설문 → 자동 ContentPlan 생성 | /survey/[token] | ✅ |
| 3 | 콘텐츠 컨펌 | 기획·원고 확인 → 승인/피드백 | /portal | ✅ |
| 4 | 리포트 열람 | 월간 보고서·성과 | /portal | ✅ |
| 5 | 커뮤니케이션 | 피드백·요청 | /portal | 🔶 |

## 핸드오프
```
최고관리자[세팅·계약] → 관리자[배분·검수] → 마케터[기획·제작·검수]
   → 거래처[설문·컨펌] → 마케터[게시·성과] → 관리자[보고] → 최고관리자[정산]
```

## 구현 순서
최고관리자 → 관리자 → 마케터 → 거래처. 각 단계마다:
① 역할 대시보드를 그 역할의 파이프라인 형태로 재구성 →
② 파이프라인 내 🔶/⬜ 빈 배선 채움 →
③ 톤앤매너(화이트 셸 + 다크모드) 적용.
