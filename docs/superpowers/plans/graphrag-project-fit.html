venom_erp_v1

마케팅 에이전시 ERP — Graph RAG 적용 파트 분석

이 ERP는 거래처(Client) → 업무(WorkItem) → 콘텐츠(ContentAsset) → 보고서(Report) → 청구(BillingRecord)로 이어지는 관계 체인을 가집니다. 마케터-거래처-업무-성과의 연결망을 Graph RAG로 탐색하면 기존 SQL 쿼리로는 불가능한 맥락 기반 인사이트를 뽑을 수 있습니다.

🗂️

현재 코드베이스와의 연결 포인트: src/server/repositories/의 각 repository 함수들이 현재 SQL 기반으로 개별 조회하는 것을 Graph RAG 노드/엣지로 전환하면 됩니다. 특히 dashboard.ts의 fetchDashboardInput()이 병렬로 여러 DB 조회를 하는 부분이 Graph RAG로 단일 그래프 탐색으로 대체할 최우선 후보입니다.

✅

ERP 프로젝트 결론: venom_erp_v1에서 Graph RAG는 선택이 아닌 필수에 가깝습니다. 특히 "마케팅 인사이트 AI"와 "업무-청구 연결 자동화"는 현재 Prisma 스키마가 이미 이상적인 그래프 구조로 설계되어 있어, Neo4j 동기화만 추가하면 즉시 구현 가능합니다.

ERP 프로젝트 Graph RAG 적용 로드맵

Phase 1 · 즉시 지금 설계에 반영

온톨로지 설계 — 현 Prisma 스키마 → Neo4j 노드/엣지 매핑

기존 prisma/schema.prisma의 모델 관계를 Arrows.app으로 시각화. Client·WorkItem·Report·BillingRecord·ContentAsset·User 6개 핵심 노드를 우선 정의.

Phase 2 · 단기 MVP 구현

대시보드 인사이트 AI — fetchDashboardInput() Graph RAG 대체

현재 src/server/repositories/dashboard.ts의 병렬 SQL 조회를 Neo4j 그래프 탐색으로 전환. 마케터별·거래처별 업무-성과-청구 연결 인사이트 자동 생성 MVP.

Phase 3 · 중기 에이전트 고도화

LangGraph 기반 마케팅 인사이트 에이전트

질의 분류 → Graph RAG 탐색(KeywordResearch+ContentAsset+Report.metrics) → 검증 → 보고서 초안 자동 생성 파이프라인. src/server/marketing/ 모듈과 연동.

Phase 4 · 장기 고도화

ERP 트랜잭션 실시간 Neo4j 동기화

Prisma 미들웨어 or CDC로 WorkItem·BillingRecord·ContentAsset 변경 시 Neo4j 자동 반영. 실시간 업무-성과-청구 그래프 기반 예측 알림.

최종 의사결정 매트릭스

두 프로젝트 중 어디에, 어떤 순서로 Graph RAG를 도입할지 우선순위를 정리합니다.

🏗️

venom_erp_v1 — 즉시 도입

설계 단계라면 지금 반영해야 합니다. Prisma 스키마가 이미 그래프 구조이므로 Neo4j 동기화만 추가하면 됩니다.

  • 현 schema.prisma를 Arrows.app으로 시각화
  • Neo4j를 DB 스택에 추가 (Prisma 미들웨어 연동)
  • fetchDashboardInput()을 Graph RAG로 1호 대체
  • 마케팅 인사이트 AI를 src/server/marketing/에 통합
  • 채널 성과 경로: PublishJob→ContentAsset→Report 연결
📊

GEO SEO — 단계적 도입

벡터 RAG로 먼저 시작하고, 키워드 관계 분석 파트만 Graph RAG로 고도화합니다.

  • 1단계: 기존 벡터 RAG로 빠른 MVP
  • 2단계: 키워드 토픽 클러스터 그래프화
  • 3단계: 경쟁사 연결망 Graph RAG 분석
  • GEO별 콘텐츠 관계 그래프 설계
  • ERP 완료 후 여력 생기면 심화 적용
