## 최상위 — 구현에 반영할 것 (근거 강도순)
1. **반복 ≥7회** (질문×엔진×일). 단일 실행은 통계적으로 불신(생성 자체가 확률적). SE<0.10에 n=7, 출처 커버리지 n=8. → `RECOMMENDED_RUNS=7`. **[반영]**
2. **다수결 접기 금지 → 분포·신뢰구간.** 비율+CI로 보고, 원시 N회 보존. → `mentionRateCI`(Wilson 95%) 추가. **[반영]**
3. **충실 인용층 추가**(`claimSupported`). Xu: 인용 문장 **11% 미지지**. 병원=거버넌스/책임 이슈. → 스키마 필드 추가. **[반영·캡처 점진]**
4. **위치·비중 필드**(`citationPosition`, `answerShare`). 위치가 인용 top driver, 흡수도가 실영향. → 스키마 필드 추가. **[반영·캡처 점진]**
5. **자동 인용-리라이트를 확정 승리로 출시 금지.** C-SEO Bench: 대다수 무효·일부 역효과. SAGEO Arena: 본문만 최적화 시 리트리벌 -9~16%·최종 인용 -6%. → 리라이트=가설(A/B), 리트리벌 순위 병행 관측. **[설계 §3.1 반영]**
6. **경쟁·오류 캡처**(`competitorsMentioned`✓, `wrongClaim`). SOV·정직성. **[wrongClaim 반영]**
7. **출처 오버랩 분리.** AIO 인용 도메인 ~30%가 오가닉 1p 밖 → SEO 순위를 GEO 대용 금지(트랙 분리 근거). **[설계 반영]**

## 핵심 논지 3
- **측정:** 노출≠인용≠충실인용≠흡수. 서베이가 GEO를 다단 확률 파이프라인(활성→크롤→리트리벌→리랭크→인용→현저성→흡수→충실도)으로 정식화. binary 1비트로 접지 말 것.
- **무엇이 실제 인용을 부르나:** GEO(Aggarwal)는 인용·통계·따옴표 추가로 최대 +40%(도메인 의존). 그러나 **What Gets Cited/C-SEO Bench/SAGEO Arena**가 이를 강하게 한정 — **관련성·순위·구조**가 문구 트릭보다 지배적, 리라이트는 리트리벌을 해칠 수 있음. → **본문 관련성·추출가능 근거(정의·수치·비교·절차)** 우선.
- **리스크:** 환각·오인용(11%·"자주 오인용"), 랭킹 조작 취약·역효과, 단일 실행 점추정의 오도. → 노출과 충실성 동시 추적, CI 표기, 조작 제안 차단.

## 우리 구현과의 정합
- 이미 일치: 측정 우선(북극성 언급률)·정직성 티어·조작 배제·엔진셋 분모 제외·측정시점 스냅샷.
- 이번 반영: 반복 7·CI(`mentionRateCI`)·충실성/위치/비중/오류 스키마 필드·리라이트=가설 거버넌스(설계 §3·§3.1).
- 후속(캡처 UI): `claimSupported`/`citationPosition`/`answerShare` 수동·자동 기록 폼, CI 밴드 차트, 리트리벌 순위 병행 관측.
