## 스키마 변경 (이 세션 유일)
- `CalendarEvent.assigneeId`(nullable) + `@@index`, `User.assignedEvents`. **additive** — `prisma db push`로 배포 시 자동 적용(무손실). C4 배포에서 적용 확인됨.

## 아키텍처 결정 (프레임 고정)
- **검색 데이터**: `SearchDataPort`(mock|naver|hybrid) 단일 계약. 하이브리드는 요청 스코프 `EffectiveTierSink`로 실제 사용 티어를 배지에 반영(폴백 시 강등).
- **P3(시계열)**: 데이터랩이 요청마다 6개월 시계열을 반환 → **저장 없이 라이브**(P3a). 장기추세 저장은 P3b(schema)로 분리.
- **캘린더**: 자체 캘린더가 본체. 외부는 표준 `.ics` **내보내기**(구글 OAuth 대신 무의존).
- **정직화**: 실측/AI/근사/미연결 4티어 + ConnectionBadge. 시뮬·규칙기반·추정은 화면에 명시.

## 남은 후속 (별도 승인/설정 필요)
- **P3b** — 시계열 스냅샷 저장(작년 동월비·장기추세). schema + 월간 캡처, 데이터 축적 후 가치.
- **캘린더 격자 클릭→수정** — 현재 수정/삭제는 하단 목록에서. 격자 이벤트 직접 클릭 편집은 격자 컴포넌트 클라이언트화 필요.
- **구글 캘린더 실시간 양방향** — opt-in, 기존 OAuth 재사용.
- **검색광고(NAVER_AD_*)** 키 추가 시 절대 월간 검색수 실측 활성화(현재 데이터랩만).
