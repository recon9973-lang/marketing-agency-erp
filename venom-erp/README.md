# VENOM ERP

VENOM 마케팅 에이전시를 위해 새로 제작한 **자체 완결형(self-contained) ERP**입니다.
빌드·설치 과정 없이 `index.html` 하나로 동작하며, 데이터는 브라우저 `localStorage`에
저장됩니다(서버 전송 없음). 기존 Next.js 기반 ERP 스택과 독립적으로 실행됩니다.

## 실행 방법

```bash
# 방법 1) 파일을 브라우저로 바로 열기
open venom-erp/index.html          # macOS
xdg-open venom-erp/index.html      # Linux

# 방법 2) 정적 서버로 서빙
npx serve venom-erp
```

## 브랜드 구성 (VENOM)

- 워드마크 로고 `VENOM` + 브랜드 오렌지 액센트 도트
- 팔레트: 브랜드 `#d9662e` / 스트롱 `#c2560f` / 소프트 `#fbeadd` / 다크 사이드바 `#1c1b19`
- 통화 KRW, 한국어 UI, 마케팅 에이전시 실무에 맞춘 시드 데이터

## 모듈

| 모듈 | 내용 |
|------|------|
| 대시보드 | 활성 클라이언트·MRR·진행 캠페인·미수금 KPI, 채널별 집행 광고비 차트, 매출 비중 도넛, 마감·우선 업무 |
| 클라이언트 | CRM — 등급/상태/월매출/담당 AE, 검색·필터·CRUD |
| 캠페인 | 채널·예산·집행·진행률·마감 관리, 소진율 집계 |
| 업무 보드 | 대기/진행/검수/완료 칸반, 카드 단계 이동·우선순위 |
| 청구·재무 | 인보이스 발행·입금확인, 수금/미수금/연체 집계 |
| 팀·근태 | 구성원 가동률, 휴가 신청·승인/반려 |
| 리포트 | ARR·평균 매출·가동률·완료율, 등급/채널 분포, 경영 요약 |
| 설정 | 조직 정보, 데이터 내보내기/가져오기(JSON), 시드 초기화 |

## 데이터

- 최초 진입 시 VENOM 샘플 데이터(팀 6명, 클라이언트 6곳, 캠페인 7건 등)로 시작합니다.
- 모든 변경은 `localStorage`에 즉시 저장됩니다.
- **설정 → 데이터 관리**에서 전체를 JSON으로 내보내거나 가져올 수 있고, 시드로 초기화할 수 있습니다.

## 기술

- 의존성 0개(바닐라 JS + 인라인 SVG 차트). CDN·외부 요청 없음 → 오프라인 동작.
- 해시 라우팅 SPA, 이벤트 위임 기반, 모달 폼으로 CRUD 처리.
