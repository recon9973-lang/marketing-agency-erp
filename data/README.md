## 주의 (조인/해석)

- **광주 코딩 불일치:** 행안부 파일은 `광주광역시`(독립)로, 심평원 병원파일은 광주 구들을
  `전남` 아래 `광주○구`로 둔다. **시도명 문자열 조인 금지** → 시군구 정규화 매퍼 필요.
- **③ 상병통계는 지역별이 아니다:** 진료과(표시과목)별 전국 실수요 구조. "검색수요↔의료전환
  갭" 프레이밍용. 구 단위 진료인원이 필요하면 심평원 *지역별* 진료통계(별도 데이터셋).
- **①에는 연령이 없다:** 남/여만. 연령대는 SGIS(`fetchRegionDemographics`)로 보완.
- **좌표계:** 병원파일은 WGS84 경위도. SGIS geocode는 UTM-K(EPSG:5179) 기본 → 반경 계산 시 통일.
