## 파생 큐레이션 데이터 (외부 API egress 차단 환경 — 코드로 정리)

`scripts/build-derived-region-data.py` 가 공개 통계를 **코드로 정리**해 만드는 오프라인 참조표.
정밀 수치가 아니라 **오디널(순위·등급) 근사**이며, 리포트·UI에 🟡/등급으로 정직 표기한다.
원본 API/파일(data.go.kr·KOSIS)이 확보되면 이 스크립트만 교체하면 된다.

| 산출물 | 근거 | 단위 | 축 | 성격 |
|---|---|---|---|---|
| `income-by-sido.json` | 통계청 「지역소득」 1인당 개인소득 시도 순위 | 17 시도 | 소득·구매력 | 상대지수(전국=100)·5분위·순위(근사) |
| `access-by-sgg.json` | 도시철도·수도권전철·KTX/SRT 운영 노선 | 시군구 255 | 접근성 | 등급 0~3(다노선환승/전철정차/광역철도/미약) |

- **소득은 시도 단위**(개인소득 시군구 미공표) → 🟡광역 표기. 시군구 정밀 소득은 국세청
  근로소득·건보료 분위 등 별도 확보 시 상향.
- **접근성은 운영 노선 기준 오디널**(좌표 아님). 반경 내 역 수(좌표) 필요 시 도시철도
  역사 좌표 데이터(전국도시철도역사정보표준데이터) 추가 확보 필요.

## 주의 (조인/해석)

- **광주 코딩 불일치:** 행안부 파일은 `광주광역시`(독립)로, 심평원 병원파일은 광주 구들을
  `전남` 아래 `광주○구`로 둔다. **시도명 문자열 조인 금지** → 시군구 정규화 매퍼 필요.
- **③ 상병통계는 지역별이 아니다:** 진료과(표시과목)별 전국 실수요 구조. "검색수요↔의료전환
  갭" 프레이밍용. 구 단위 진료인원이 필요하면 심평원 *지역별* 진료통계(별도 데이터셋).
- **①에는 연령이 없다:** 남/여만. 연령대는 SGIS(`fetchRegionDemographics`)로 보완.
- **좌표계:** 병원파일은 WGS84 경위도. SGIS geocode는 UTM-K(EPSG:5179) 기본 → 반경 계산 시 통일.
